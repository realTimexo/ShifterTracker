ShifterTracker 1.1.0 — Quick start

1. Extract the ZIP and run ShiftTracker.exe. No Python or separate .NET runtime is needed.
2. Under CAMERA SETTINGS, scan for the camera and press Connect. Select the correct perspective, rotate/mirror the preview as needed.
3. Choose V3 · track the knob. Click the center of the visible knob in the live preview. After a restart, click once again to initialize this session's optical-flow track.
4. Move the lever to each displayed position and click its Capture button on the left. For V2 shift protocol, teach N-L, N and N-R too. Use the calibration progress count to check all required positions.
5. Choose Keyboard, Built-in virtual Xbox gamepad, or vJoy under Output. Select each state's binding, then press Start output and Arm detection.
6. Bind those same keys/buttons to the corresponding gear actions in BeamNG. ShifterTracker does not edit BeamNG's control setup.
7. Check the current-position indicator, H-pattern highlight and compact developer log while stationary before using the shifter in a game.

Tracker choices are independent of shift protocol. V1 is the fixed-camera tracker. V2 aligns the whole frame from stable outer-housing features. V3 tracks features on the knob itself with optical flow; it does not stabilize the background or compare per-gear pictures. A small camera shift may be tolerated, but changes of view still require recalibration. If V3 loses the knob, click its center in the live preview to reacquire it.

The built-in virtual gamepad requires Windows administrator approval. HIDMaestro 2.0.0 may update an older virtual-device driver once after upgrading from 1.x. Exit older ShifterTracker versions before starting the new virtual-gamepad mode, read the in-app notice, then decide whether to approve Windows prompts. Keyboard output does not install a driver. vJoy must be installed and configured separately.

Settings and learned gear coordinates are saved in %LOCALAPPDATA%\ShifterTracker\settings.json. Startup diagnostics are saved in %LOCALAPPDATA%\ShifterTracker\startup.log.

Test in a stationary vehicle first. ShifterTracker is an input prototype, not safety-critical control software.
